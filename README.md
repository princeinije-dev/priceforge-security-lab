# PriceForge Security Lab
Built by Prince Inije

**PriceForge Security Lab** is a deliberately vulnerable e-commerce application built to practice real-world web application security testing in a controlled local environment.

The project simulates an online shopping platform and includes intentionally introduced security flaws across authentication, authorization, input handling, and business logic.

Rather than relying only on theoretical exercises, this lab provides a realistic application where vulnerabilities can be investigated through browser behavior, HTTP requests, and server-side code.

## Project Objectives

- Build and understand a realistic Node.js web application
- Practice manual web application penetration testing
- Identify and validate common security vulnerabilities
- Analyze HTTP requests and responses using Burp Suite
- Document findings with reproducible steps and screenshots
- Understand vulnerable implementations and their secure alternatives

## Technology Stack

- Node.js
- Express.js
- PostgreSQL
- EJS
- JavaScript
- Burp Suite Community Edition

## Security Testing Areas

The lab includes practical exercises involving:

- Insecure Direct Object Reference (IDOR)
- SQL Injection
- Cross-Site Scripting (XSS)
- Client-Side Price Manipulation
- Broken Access Control
- Business Logic Vulnerabilities
- Additional web security weaknesses and secure implementation comparisons

## Project Status

Actively developed. Vulnerability documentation, evidence screenshots, and security report improvements are ongoing.

## Disclaimer

PriceForge Security Lab is intentionally vulnerable and intended for educational purposes and authorized security testing only. Run it locally or in a controlled environment. Do not expose the vulnerable application to the public internet.
